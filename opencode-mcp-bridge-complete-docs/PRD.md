# Product Requirements Document

## P0

### Connection
- Detect OpenCode availability.
- Authenticate to OpenCode.
- Display connection health.

### Sessions
- Create a coding session.
- Send prompts.
- Receive progress/events.
- Stop a running session.
- Reconnect to an existing session.

### GUI
- Single command box.
- AI client connection list.
- OpenCode status.
- Session status.
- Output stream.
- Diff view.
- Approval controls.

### MCP
- Expose bridge capabilities as MCP tools.
- Support tool discovery.
- Validate all tool inputs.
- Enforce permissions.

### Repository
- Show selected workspace/repository.
- Read git status and diff.
- Never silently change repositories.

## P1

- persistent session metadata
- execution history
- audit logs
- GitHub integration
- review feedback
- restart/recovery
- multi-AI client profiles

## P2

- workflow automation
- queued jobs
- richer dashboards
- remote device pairing
