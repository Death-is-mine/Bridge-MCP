# Local Development

## Prerequisites

- Node.js
- npm/pnpm
- OpenCode
- Git

## Run OpenCode

```bash
OPENCODE_SERVER_PASSWORD="<secret>" opencode serve --hostname 127.0.0.1 --port 4096
```

## Run Bridge

Use the repository's package scripts once implementation exists.
