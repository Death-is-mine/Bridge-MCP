# Error Handling

Use stable error codes.

Examples:
- BRIDGE_UNAVAILABLE
- OPENCODE_UNAVAILABLE
- OPENCODE_AUTH_FAILED
- SESSION_NOT_FOUND
- REPOSITORY_NOT_FOUND
- PERMISSION_DENIED
- APPROVAL_REQUIRED
- GITHUB_AUTH_FAILED
- STREAM_DISCONNECTED
- INVALID_ARGUMENT

Never return internal stack traces to remote clients.
