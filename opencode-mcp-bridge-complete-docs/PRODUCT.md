# Product

## Product statement

OpenCode MCP Bridge is a lightweight web control plane for sending work from MCP-capable AI clients to an OpenCode instance running on the user's machine.

## Primary users

- developers using OpenCode
- users who want to control local coding work from a phone or browser
- users who use multiple AI clients

## Product characteristics

- simple
- web-first
- AI-provider agnostic
- local-first execution
- secure by default
- observable
- easy to understand

## Non-goals for v1

- replacing OpenCode
- building a general-purpose shell
- becoming a full Git hosting product
- autonomous production deployment
- pretending every AI client supports MCP
